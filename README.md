# 🐝 蜂群智能运营工作台 / Swarm Intelligence Operations Workbench

> 连锁药房会员增长多智能体系统 — 课堂作业演示 Demo

## 在线预览 / Live Preview

直接浏览器打开 `index.html` 即可，无需服务器。

## 项目说明

本 Demo 为纯前端 HTML 页面，用于演示**多智能体蜂群协同**在医药零售场景中的应用。

### 核心创新

1. **蜂群协商** — 5个专业Agent群聊式协商，2.3秒达成共识
2. **策略基因** — 成功策略自动结晶，可跨门店复制
3. **数字孪生** — 策略风洞仿真，执行前先推演

### 页面结构

| 页面 | 内容 |
|------|------|
| 工作台首页 | 蜂群全局状态、今日信号、协商结果 |
| 气象哨兵 | 天气-疾病关联预测 |
| 慢病管家 | 复购周期追踪、会员画像 |
| 库存预言家 | 库存热力图、需求预测 |
| 舆情雷达 | 公共卫生事件监控 |
| 策略指挥官 | 多Agent协商室（核心页面） |
| 数字孪生 | 策略风洞仿真（预留） |

## 文件结构

```
pharmacy-swarm-demo/
├── index.html    # 页面结构（HTML）
├── style.css     # 样式（CSS）
├── script.js     # 交互逻辑（JS）
└── README.md
```

### 协作分工建议

| 文件 | 改什么 | 适合谁 |
|------|--------|--------|
| `index.html` | 文案、数据、页面结构 | 所有人 |
| `style.css` | 颜色、布局、间距、动画 | 熟悉CSS的同学 |
| `script.js` | 页面切换、交互逻辑 | 熟悉JS的同学 |

## 技术栈

- HTML + CSS + Vanilla JS（三文件分离）
- 无外部依赖（字体除外）
- 适配 1440px+ 宽度
