# 门店执行 Agent 设计

## 1. Agent 定位

门店执行 Agent 是连接总部策略和门店一线执行的智能体，负责将总部运营或主控 Agent 生成的活动方案，拆解成门店店长和店员能够直接执行的任务。

**一句话概括：** 门店执行 Agent 的作用是把“总部活动方案”翻译成“门店今日任务”。

## 2. 解决的业务痛点

- 总部活动下发后，门店不知道重点做什么；
- 店员面对会员时缺少临场服务辅助；
- 门店执行结果难以及时回传；
- 活动执行依赖人工经验，缺少标准化任务闭环。

## 3. 输入信息

| 来源 | 输入内容 |
| --- | --- |
| 主控 Agent | 活动目标、执行优先级 |
| 活动策略 Agent | 活动方案、券包规则、触达渠道、推荐话术 |
| 会员洞察 Agent | 重点会员名单、会员标签、复购周期、购买偏好 |
| 药品匹配 Agent | 推荐药品、关联品类、合规提醒 |
| 库存履约 Agent | 门店库存、缺货风险、补货建议 |
| 门店系统 | 店长确认、店员执行、会员核销记录 |

## 4. 核心功能

1. **任务拆解**：把活动目标拆分为今日重点动作、责任人和完成标准。
2. **店长任务生成**：生成库存检查、人员安排、陈列准备、活动确认等任务。
3. **店员话术辅助**：为不同会员场景提供合规、简洁的服务提醒话术。
4. **会员到店服务提示**：当重点会员到店时，提示其标签、近期需求和适合承接的活动。
5. **库存与补货提醒**：结合活动需求识别库存不足、近效期压力和补货建议。
6. **执行反馈回传**：同步任务完成度、核销情况、会员反馈和门店承接情况。
7. **异常上报**：对缺货、店长未确认、店员执行率低等情况发出提醒。

## 5. 输出结果

| 输出对象 | 输出内容 |
| --- | --- |
| 给店长 | 今日任务清单、补货建议、活动承接提醒 |
| 给店员 | 会员服务提示、推荐话术、券核销提醒 |
| 给主控 Agent | 门店执行状态、异常情况、任务完成度 |
| 给复盘优化 Agent | 活动执行数据、会员反馈、门店反馈 |

## 6. 典型流程示例：寒潮天气触发慢病会员提醒

1. 信号感知 Agent 识别到未来 72 小时将明显降温。
2. 主控 Agent 判断需要发起慢病会员健康提醒活动。
3. 会员洞察 Agent 筛选出近期存在复购需求的慢病会员。
4. 库存履约 Agent 检查相关药品库存和缺货风险。
5. 活动策略 Agent 生成活动方案、触达渠道、券包规则和建议话术。
6. 门店执行 Agent 将方案拆解为店长任务和店员任务：
   - 店长：确认活动、检查库存、安排重点会员承接；
   - 店员：查看重点会员名单、使用健康提醒话术、完成核销承接。
7. 店长在工作台确认任务。
8. 店员根据提示完成会员服务。
9. 门店系统将确认情况、执行情况、核销记录和异常反馈回传。

## 7. 合规注意事项

- 店员话术应以健康提醒和合规推荐为主，不能替代医生诊断；
- 不能直接说“你必须吃某某药”；
- 涉及会员购药记录和慢病标签时，要注意权限控制、最小可见范围和隐私保护；
- 药品推荐需要结合适应症、禁忌和门店合规要求，避免夸大宣传。
