# 复盘优化 Agent 设计

## 1. Agent 定位

复盘优化 Agent 是整个业务闭环的最后一环，负责分析活动执行效果，找出转化好或转化差的原因，并把有效经验沉淀为下一轮可复用的策略模板。

**一句话概括：** 复盘优化 Agent 的作用是把“活动结果”转化为“下一轮策略优化建议”。

## 2. 解决的业务痛点

- 传统复盘只看销售额和核销率，不知道原因；
- 复盘依赖人工导表和 Excel，效率低；
- 门店差异难以解释；
- 成功经验无法沉淀复用；
- 下一轮活动优化缺少依据。

## 3. 输入信息

| 来源 | 输入内容 |
| --- | --- |
| 活动策略 Agent | 活动目标、活动方案、券包规则、目标人群 |
| 门店执行 Agent | 店长确认情况、店员触达情况、门店反馈 |
| 会员触达系统 | 触达人数、打开率、点击率、领券率 |
| POS/交易系统 | 到店购买、核销、销售额、客单价 |
| 库存系统 | 库存变化、缺货情况、近效期消化情况 |
| 会员系统 | 复购情况、会员活跃度、沉睡会员唤醒情况 |

## 4. 核心功能

1. **活动效果分析**
2. **原因归因**
3. **门店差异分析**
4. **会员分群效果分析**
5. **优化建议生成**
6. **策略评分**
7. **策略模板沉淀**

## 5. 关键指标

| 指标类型 | 关键指标 |
| --- | --- |
| 触达指标 | 触达人数、打开率、点击率 |
| 转化指标 | 领券率、核销率、购买转化率 |
| 销售指标 | 销售额、客单价、重点品类销售额 |
| 会员指标 | 复购率、活跃会员数、沉睡会员唤醒数 |
| 库存指标 | 库存消化率、缺货率、补货及时率 |
| 门店执行指标 | 任务完成率、店员触达率、门店承接率 |

## 6. 原因归因示例

| 现象 | 可能原因 |
| --- | --- |
| 打开率低 | 触达时间不合适、标题吸引力不足、会员人群不精准 |
| 领券率低 | 优惠力度不足、药品需求不强、推荐品类不匹配 |
| 核销率低 | 门店距离远、券有效期太短、店员承接不足 |
| 销售额低 | 客单价低、关联推荐不足、重点药品库存不足 |
| 某些门店效果差 | 店长未确认任务、店员执行率低、库存不支持活动 |

## 7. 策略模板沉淀示例：降温感冒药触达模板

| 模板要素 | 内容 |
| --- | --- |
| 触发条件 | 未来 72 小时降温超过 8℃ |
| 目标人群 | 过去 6 个月购买过感冒药、止咳药的会员 |
| 推荐品类 | 感冒药、止咳药、退烧药 |
| 触达时间 | 降温前 1—2 天 |
| 触达渠道 | 企微优先，短信补充 |
| 门店任务 | 检查库存，准备活动承接 |
| 复盘指标 | 打开率、核销率、销售额、库存消化率 |

该模板并不是固定不变的活动答案，而是把一次有效经验沉淀成下一轮可复用的起点，便于主控 Agent 在相似场景下快速调用，再结合当期会员和库存情况做适配。
