## 交互说明（已实现）

- **全局左侧导航**：品牌区为 **Logo 字标「副」+「数字副店长」主标题 + 副标题**；菜单项为 **彩色图标块 + 中文标签**（对齐可读性，参照飞书工作台信息层级，略宽侧栏约 228px）。
- **工作台布局**：纵向 **`wb-workbench` 统一间距**；首页指标为 **4 张独立数据卡片**（与 Hero 分离）；中间区 **机会列表与 AI 助手双栏等高对齐**；**全部应用** 置于同一白底卡片内，与应用网格对齐。
- **顶栏右侧**：**角色切换**（总部运营 / 门店店长 / 门店店员），更新头像字、姓名/岗位与副标题中的「总部视图 / 店长视图 / 店员视图」（Demo，不接权限）。
- **常用应用 / 添加常用**：打开 Modal（示意飞书「添加常用」）。
- **全部应用**：分类 Tab 筛选（最近使用 / 会员增长 / 门店履约 / 数据分析）。
- **门店执行**：店长视图与店员视图切换；店员页含合规风险提示文案。
- **策略模板**：**新增策略模板** 按钮打开表单弹窗，保存后在列表顶部插入卡片（含「新建」标签，前端示意不落库）。
- **跨页跳转**：工作台内按钮可跳到门店活动、会员洞察等（`navigate`）。

## 运行方式

直接用浏览器打开项目根目录下的 `index.html`，无需构建与服务器。
