# B 端工作台 UI 设计规范

**产品**：数字副店长工作台  
**版本**：v1.0（与 PRD MVP v1.0 对齐）  
**参考意向**：飞书「工作台」——深蓝全局侧栏、浅灰内容区、白卡片应用网格、顶栏搜索与通知、「常用应用」+「全部应用」分类 Tab、「添加常用」弹窗（搜索 + 左侧分类 + 右侧列表）。意向截图建议置于 `docs/assets/workbench-reference.png` 便于团队归档（若仅存于本地 Cursor 资源目录，请在评审材料中另行附上）。

**关联文档**：[PRD-数字副店长工作台-MVP.md](./PRD-数字副店长工作台-MVP.md)

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 场景优先 | 用户按 **业务场景** 找能力（会员洞察、策略运营等），不按 Agent 名称分区。 |
| 一层直达 | 「工作台首页」聚合今日机会；高频模块放入 **常用应用**，减少点击深度。 |
| 专业可信 | 医药 B 端克制用色；强调 **可读性、可审计**（状态、时间、操作者）。 |
| 可扩展 | 「全部应用」用 **分类 Tab + 网格**，后续加模块不改导航骨架。 |
| 角色差异 | 总部钉选「洞察 / 策略 / 复盘」；门店钉选「门店执行」。 |

## 2. 全局布局壳（Application Shell）

```
┌─────────────────────────────────────────────────────────────┐
│ [Logo]  │  顶栏：面包屑 / 标题          搜索 Cmd+K   通知   用户 │
│ 全局    ├─────────────────────────────────────────────────────┤
│ 窄侧栏  │ 可选：多文档 Tab（工作台 │ 会员洞察 │ ×）              │
│ 图标    ├─────────────────────────────────────────────────────┤
│ 导航    │  内容区（浅灰底）                                        │
│         │    ┌─────────────────────────────────────────────┐   │
│         │    │ 页面内容（白卡片 / 栅格）                     │   │
│         │    └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

| 区域 | 宽度 / 高度 | 行为 |
|------|-------------|------|
| 全局侧栏 | **220–240px**（可读优先）或收起为 **56–72px** 仅图标 | **Logo + 产品名 + 副标题**；以下为 **图标色块 + 中文菜单**；当前项高亮（左侧指示条或浅底） |
| 顶栏 | 56–64px 高 | 与工作台内容左对齐；搜索框可选居中或右侧。 |
| 内容区 | 剩余宽度 | 最大内容宽建议 `min(100%, 1440px)` 居中，两侧留白。 |

## 3. 设计令牌（Design Tokens）

以下为 **建议默认值**，实现时使用 CSS 变量，禁止魔法数字散落组件。

### 3.1 色彩

| Token | 用途 | 建议值（浅色主题） |
|-------|------|---------------------|
| `--wb-sidebar-bg` | 全局侧栏背景 | `#101828` |
| `--wb-sidebar-icon` | 侧栏默认图标 | `rgba(255,255,255,0.65)` |
| `--wb-sidebar-icon-active` | 侧栏选中 | `#ffffff` |
| `--wb-sidebar-item-hover` | 侧栏项悬停底 | `rgba(255,255,255,0.08)` |
| `--wb-shell-bg` | 内容区画布背景 | `#f2f3f5` |
| `--wb-card-bg` | 卡片表面 | `#ffffff` |
| `--wb-border` | 分割线 / 描边 | `#e5e7eb` |
| `--wb-text-primary` | 主文案 | `#111827` |
| `--wb-text-secondary` | 次要文案 | `#6b7280` |
| `--wb-text-muted` | 辅助 / 禁用 | `#9ca3af` |
| `--wb-brand` | 主按钮 / 强调链接 | `#2563eb`（可选 `#3370ff` 贴近飞书蓝） |
| `--wb-brand-hover` | 主按钮悬停 | `#1d4ed8` |
| `--wb-success` | 成功 | `#059669` |
| `--wb-warning` | 警示 | `#d97706` |
| `--wb-danger` | 危险 / 驳回 | `#dc2626` |
| `--wb-info` | 信息 | `#0284c7` |

### 3.2 Hero 横幅（工作台首页顶部）

| Token | 建议 |
|-------|------|
| `--wb-hero-from` | `#1e40af` |
| `--wb-hero-to` | `#3b82f6` |
| Hero 内文字 | `#ffffff`，次级 `rgba(255,255,255,0.85)` |

### 3.3 圆角与阴影

| Token | 值 |
|-------|-----|
| `--wb-radius-sm` | `6px`（标签、小按钮） |
| `--wb-radius-md` | `10px`（卡片、输入框） |
| `--wb-radius-lg` | `12px`（Modal、大面板） |
| `--wb-shadow-card` | `0 1px 2px rgba(16,24,40,0.06), 0 1px 3px rgba(16,24,40,0.1)` |
| `--wb-shadow-modal` | `0 12px 32px rgba(16,24,40,0.12)` |

### 3.4 间距（8px 网格）

| Token | 值 |
|-------|-----|
| `--wb-space-1` ~ `--wb-space-8` | `4, 8, 12, 16, 24, 32, 40, 48px` |

卡片内边距默认 `--wb-space-4`（16px）；区块纵向间距 `--wb-space-5`（24px）。

## 4. 字体与排版

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 22–24px | 600 | 页面标题 |
| H2 | 16–18px | 600 | 卡片标题、分区标题 |
| Body | 14px | 400 | 正文 |
| Caption | 12–13px | 400 | 辅助说明、表格次要列 |
| KPI 数字 | 24–32px | 600–700 | 仪表盘指标（可选用 tabular nums） |

**字体栈（中文）**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Microsoft YaHei", sans-serif`

行高：正文 `1.5`–`1.6`；标题 `1.3`。

## 5. 工作台首页模块规范

### 5.1 上半区：Hero + 常用应用

**布局**：左侧 Hero（约 `minmax(320px, 1fr)`），右侧「常用应用」网格（`repeat(auto-fill, minmax(160px, 1fr))`）。

**Hero**

- 一句话价值主张（示例）：「用数据把会员资产变成今日可执行任务。」
- 可选次要按钮：`显示设置`（与工作台排列相关时）、跳转帮助。
- 可与 PRD 指标合并：在 Hero 底部增加 **一行紧凑 KPI**（今日机会数、待审核活动数），字号小于主标题。

**常用应用卡片**

- 结构：**彩色图标区（40×40）** + **标题（单行省略）**。
- 图标背景：浅色底 + 饱和点缀色（橙/绿/红/蓝区分品类，与医药场景协调即可）。
- **添加常用**：虚线边框 `border: 1px dashed var(--wb-border)`，居中 `+`，Hover 时边框 `--wb-brand`。

### 5.2 下半区：全部应用

**分类 Tab**

- 横向滚动容器；当前 Tab 下划线或浅色胶囊底。
- **建议分类与 PRD 映射**：

| Tab 标签 | 包含应用（示例） |
|----------|------------------|
| 最近使用 | 按本地存储或后端记录排序 |
| 会员增长 | 会员洞察、策略运营、策略模板 |
| 门店履约 | 门店执行（店长视图）、门店执行（店员视图） |
| 数据分析 | 活动复盘 |
| 系统设置 | 显示设置、权限（MVP 可合并或隐藏） |

**应用大卡（相对常用区略大）**

- 图标 + 标题 + **一行描述**（≤ 36 字）。
- 右侧或底部：`添加至常用` / `已添加` 文字按钮。

## 6. 「添加常用」Modal

| 元素 | 规范 |
|------|------|
| 宽度 | `min(720px, 92vw)` |
| 顶栏 | 标题「添加常用」+ 关闭 |
| 搜索 | 全宽输入框，`placeholder`「搜索应用」 |
| 主体 | **左侧** 分类列表（宽 160–200px）；**右侧** 应用列表 |
| 列表行 | 图标 + 标题 + 描述 + `添加` / `已添加` |
| 键盘 | `Esc` 关闭；搜索框 `focus` Trap 首焦点 |
| 遮罩 | `rgba(15,23,40,0.45)` |

## 7. 业务页面内通用组件（壳外内容区）

除工作台首页外，PRD 模块统一遵守：

| 组件 | 规范 |
|------|------|
| 页面标题区 | 左标题 + 右主操作（Primary）；次级操作为 Outline |
| 筛选条 | 白底条贴 `--wb-border` 底；控件间距 `--wb-space-3` |
| 表格 | 斑马纹可选；行高 44–48px；操作列右对齐 |
| 抽屉 / 侧栏 | 宽度 `400–480px`；复杂表单可用 Tab |
| Badge | 小号胶囊：`draft` 灰、`pending_review` 琥珀、`running` 绿 |
| Agent 标签 | 不占一级导航；用于详情 **次要标签**：`来源：信号感知` |

## 8. 状态与反馈

| 场景 | 表现 |
|------|------|
| 加载 | 卡片 Skeleton（灰块动画），禁止布局跳动 |
| 空状态 | 插画或简化图标 + 一句引导 + 主按钮 |
| 错误 | 顶部 Banner 或内联文案 + `重试` |
| 成功 | Toast 2–3s 消失（审核通过、补货确认等） |

## 9. 响应式

| 断点 | 行为 |
|------|------|
| ≥1280px | 完整双栏 Hero + 网格 |
| 1024–1279px | Hero 与常用应用纵向堆叠；网格列数减 1 |
| ≤1023px | 全局侧栏收起为汉堡菜单；Modal 全屏或贴底 |

---

## 10. 无障碍（基线）

- 可聚焦控件可见 **焦点环**（`outline` 或 `box-shadow`，勿仅靠颜色）。
- 图标按钮必须 `aria-label`。
- 对比度：正文与背景对比 ≥ 4.5:1（大标题可适当放宽）。
